# CampusConnect - Project Documentation

## Project Title
CampusConnect – College Event & Student Management Portal

## Duration
1 Month

## Project Type
Full-Stack Web Development Group Project

## Objective
To provide a centralized platform where students can discover and register for college events while administrators can create events and monitor registrations.

## Main Modules
1. Authentication
2. Student Management
3. Event Management
4. Event Registration
5. Student Dashboard
6. Admin Dashboard
7. Database Management

## Architecture

Frontend -> REST API -> Node.js/Express -> MySQL

## Testing
Test registration, login, event listing, event registration, admin event creation, statistics, and profile access locally before deployment.

## Future Enhancements
- Event editing and deletion UI
- QR-code attendance
- Email notifications
- Feedback and ratings
- Charts and analytics
- Certificate generation
