# CampusConnect

CampusConnect is a full-stack college event and student management portal built for a one-month web development group internship.

## Technology

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Node.js
- Express.js
- MySQL
- JWT Authentication
- bcryptjs

## Features

- Student registration and login
- Admin login
- JWT authentication
- Student dashboard
- Event listing
- Event search
- Event registration
- Registered-events dashboard
- Student profile
- Admin statistics
- Admin event creation
- Registration management
- Responsive UI

## Setup

### 1. Database

Open MySQL Workbench and run:

database/campusconnect.sql

### 2. Configure database

Open:

backend/.env

Set your MySQL password:

DB_PASSWORD=your_mysql_password

### 3. Install dependencies

Open a terminal inside the backend folder:

npm install

### 4. Start server

npm start

Server:

http://localhost:5000

### 5. Run frontend

Open frontend/index.html with VS Code Live Server.
